<h1><strong>RPG Class System</strong></h1>

<h2><strong>Descrição</strong></h2>
<p align="justify">
  Repositório criado como parte de um desafio de orientação a objetos, onde desenvolvi uma classe genérica que representa um herói de uma aventura. A classe possui propriedades como nome, idade e tipo, e um método chamado atacar(), que exibe uma mensagem personalizada conforme o tipo do herói.
</p>

<h2><strong>Tecnologias Utilizadas</strong></h2>
<ul>
  <li align="justify"><a href="https://developer.mozilla.org/en-US/docs/Web/JavaScript"><strong>JavaScript</strong></a>: Linguagem utilizada para desenvolver a classe e o comportamento do herói.</li>
  <li align="justify"><a href="https://nodejs.org/"><strong>Node.js</strong></a>: Para executar o script localmente.</li>
  <li align="justify"><a href="https://github.com/"><strong>GitHub</strong></a>: Para versionar e armazenar o projeto.</li>
  <li align="justify"><a href="https://developer.mozilla.org/pt-BR/docs/Web/HTML"><strong>HTML</strong></a>: Para formatar este arquivo README</li>
</ul>
