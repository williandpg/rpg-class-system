<h1><strong>RPG Class System</strong></h1>

<h2><strong>Descrição</strong></h2>
<p align="justify">
  Repositório criado como parte de um desafio de orientação a objetos. Neste projeto, desenvolvi uma classe genérica que representa um herói de uma aventura. A classe contém propriedades como <strong>nome</strong>, <strong>idade</strong> e <strong>tipo</strong>, além do método <code>atacar()</code>, que exibe uma mensagem personalizada de acordo com o tipo do herói.
</p>

<h2><strong>Funcionalidades</strong></h2>
<ul>
  <li align="justify">Representação genérica de heróis através de uma classe orientada a objetos.</li>
  <li align="justify">Método <code>atacar()</code> com saída personalizada conforme o tipo de herói.</li>
  <li align="justify">Estrutura simples e ideal para introdução a POO e criação de objetos.</li>
</ul>

<h2><strong>Tecnologias Utilizadas</strong></h2>
<ul>
  <li align="justify"><a href="https://developer.mozilla.org/en-US/docs/Web/JavaScript"><strong>JavaScript</strong></a>: Linguagem utilizada para desenvolver a classe e o comportamento do herói.</li>
  <li align="justify"><a href="https://nodejs.org/"><strong>Node.js</strong></a>: Utilizado para executar o script localmente.</li>
  <li align="justify"><a href="https://github.com/"><strong>GitHub</strong></a>: Versionamento e armazenamento do código.</li>
</ul>

  <h1><strong>RPG Class System</strong></h1>

  <h2><strong>Description</strong></h2>
  <p align="justify">
    Repository created as part of an Object-Oriented Programming challenge. In this project, I created a generic class representing an adventure hero. The class includes properties such as <strong>name</strong>, <strong>age</strong>, and <strong>type</strong>, and a method called <code>attack()</code> that displays a personalized message based on the hero type.
  </p>

  <h2><strong>Features</strong></h2>
  <ul>
    <li align="justify">Generic hero class using object-oriented principles.</li>
    <li align="justify"><code>attack()</code> method outputs a custom message depending on the hero type.</li>
    <li align="justify">Simple structure perfect for learning object creation and OOP basics.</li>
  </ul>
